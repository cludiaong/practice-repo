# GitHub Practice Project (Week 10)

A small, safe-to-break repository for practicing the team Git workflow:
**Clone → Work → Commit → Pull → Push**

## How to use it

1. Clone this repository with GitHub Desktop.
2. Open `Assets/Scripts/PlayerMove.cs` and make a small edit (e.g. change the `moveSpeed` number or add a comment).
3. Commit your change with a short message.
4. Pull, then Push.
5. Do the loop again with a teammate. Try editing the **same file** to see how Git combines both changes — and what happens if you both edit the exact same line (that's a merge conflict, and it's normal).

Nothing here is graded. This project exists only so you can practice the workflow safely before using it on your real team project.

## What's inside

- `.gitignore` — the standard Unity template, already set up
- `Assets/Scripts/PlayerMove.cs` — one tiny placeholder script to edit
- `ProjectSettings/` and `Packages/` — minimal placeholders so the folder looks like a real Unity project
